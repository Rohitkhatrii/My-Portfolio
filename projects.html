Rocket Rush

Unity | C#

Built a physics-based 2D Rocket landing game using Unity and C#, focusing on responsive movement and gameplay mechanics.

  • Implemented the Singleton pattern to provide centralized, controlled access to core gameplay systems.
  • Applied the Observer pattern and event-driven architecture to decouple gameplay, audio, visual effects, scoring, and game-state systems.
  • Implemented physics-based movement, collision detection, fuel management, landing validation, and dynamic scoring based on landing speed and angle.
  • Integrated Unity Input System, Cinemachine, Particle Systems, and Level management to create responsive controls, camera behavior, visual feedback, and multi-level gameplay.
